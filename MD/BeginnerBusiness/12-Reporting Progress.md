# Reporting Progress 汇报进度

## 1. 说进展

| 说法 | 例句 | 中文对照 |
|---|---|---|
| We're on track. | **We're on track** for the end of the month. | 我们按计划走，月底能完成。 |
| It's almost done. | **It's almost done** — just the last section. | 快好了，就差最后一节。 |
| We've finished the first part. | **We've finished the first part** — testing is next. | 第一部分做完了，接下来是测试。 |
| Things are moving. | **Things are moving** — slowly, but moving. | 有进展，慢是慢，但在走。 |
| We're halfway there. | **We're halfway there** — 300 of 600 done. | 做了一半，600 里做完 300。 |
| So far so good. | **So far so good** — no issues yet. | 目前一切顺利，还没有问题。 |

## 2. 说完成和没完成

| 说法 | 例句 | 中文对照 |
|---|---|---|
| I've finished + 事情. | **I've finished** the October report. | 十月的报告我做完了。 |
| I'm still working on it. | **I'm still working on it** — Friday, I promise. | 我还在做，周五给你。 |
| I haven't started yet. | **I haven't started yet** — I was on another job. | 我还没开始，之前在做别的。 |
| It's done, but not checked. | **It's done, but not checked** — Anna will review. | 做完了但没核，Anna 会审。 |
| I sent it this morning. | **I sent it this morning** — did you get it? | 我今早发了，你收到了吗？ |

## 3. 说延期

| 说法 | 例句 | 中文对照 |
|---|---|---|
| We're a bit behind. | **We're a bit behind** — about three days. | 我们有点落后，大概三天。 |
| It's going to be late. | **It's going to be late** — the test failed twice. | 会晚，测试失败两次了。 |
| We lost two days. | **We lost two days** waiting for the samples. | 等样品耽误了两天。 |
| I need two more days. | **I need two more days** to do it properly. | 我还需要两天才能做扎实。 |
| It's taking longer than we thought. | **It's taking longer than we thought.** | 比我们预想的费时间。 |
| Sorry, that's on me. | **Sorry, that's on me** — I missed the deadline. | 抱歉是我的问题，我误了期限。 |

## 4. 说时间点

| 说法 | 例句 | 中文对照 |
|---|---|---|
| I'll have it by + 时间. | **I'll have it by** Friday afternoon. | 我周五下午前给你。 |
| By end of day. | **By end of day** — before I leave. | 今天下班前给你。 |
| Early next week. | **Early next week** — Monday or Tuesday. | 下周初，周一周二。 |
| The deadline is + 时间. | **The deadline is** November 15. | 截止期是 11 月 15 号。 |
| I'll send an update every Friday. | **I'll send an update every Friday.** | 我每周五发一次进度。 |
| Two weeks from now. | **Two weeks from now** — around the 20th. | 两周后，大概 20 号。 |

## 5. 说卡住了

| 说法 | 例句 | 中文对照 |
|---|---|---|
| We're waiting for + 东西. | **We're waiting for** the samples from the factory. | 我们在等工厂的样品。 |
| I need the file from Mark. | **I need the file from Mark** before I can start. | 我得先拿到 Mark 的文件才能开始。 |
| We're blocked on + 事情. | **We're blocked on** the payment approval. | 卡在付款审批上了。 |
| The client hasn't replied. | **The client hasn't replied** — chasing them today. | 客户还没回，今天催。 |
| Can you unblock this? | **Can you unblock this** for me? | 你能帮我推一下吗？ |
| It's out of my hands. | **It's out of my hands** — it's with legal now. | 这我控制不了，在法务那边。 |

## 6. 常见错误

| 常见错误 | 正确说法 | 说明 |
|---|---|---|
| I have finished it yesterday. | I finished it yesterday. | 有明确过去时间用一般过去时。 |
| The project is going well until now. | The project is going well so far. | until now 暗示之前不顺，用 so far。 |
| I am working on it since Monday. | I've been working on it since Monday. | since 配现在完成进行时。 |
| It will be finish next week. | It'll be finished next week. | 被动要 be + 过去分词。 |
| I didn't finished the report. | I didn't finish the report. | did 后面用原形。 |
| The report is almost finish. | The report is almost finished. | 形容词用 finished。 |

## 7. Discussion 讨论

| Question | 中文对照 |
|---|---|
| How often do you report progress to your boss? | 你多久跟老板汇报一次进度？ |
| Do you say "on track" when you're not? | 不顺利的时候你会说一切正常吗？ |
| What do you do when you're blocked? | 卡住的时候你会怎么办？ |
| Are deadlines in your team realistic? | 你们组的截止期现实吗？ |
| Would you rather report early or wait until it's done? | 你愿意早汇报还是做完了再说？ |
