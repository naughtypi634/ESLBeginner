# Performance, Pay and Promotion 绩效、加薪与升职

## 1. 一对一谈话

| 说法 | 例句 | 中文对照 |
|---|---|---|
| Can we set up a one-on-one? | **Can we set up a one-on-one** this week? | 这周能做次一对一吗？ |
| How do you think I'm doing? | **How do you think I'm doing** on the project? | 你觉得我在这个项目上做得怎么样？ |
| I'd like some feedback. | **I'd like some feedback** on my work. | 我想听听对我工作的反馈。 |
| What should I focus on next quarter? | **What should I focus on** next quarter? | 下季度我该重点抓什么？ |
| Is there anything I should improve? | **Is there anything I should improve?** | 有什么我需要改进的吗？ |
| Thanks for being straight with me. | **Thanks for being straight with me.** | 谢谢你跟我说实话。 |

## 2. 说自己的成绩

| 说法 | 例句 | 中文对照 |
|---|---|---|
| I led + 事情. | **I led** the Suzhou launch last quarter. | 上个季度苏州的上市是我牵头的。 |
| I cut + 事情 + by + 数字. | **I cut** the processing time **by** 30%. | 我把处理时间缩短了 30%。 |
| I took over + 事情. | **I took over** the account when Lei left. | 磊走之后那个客户是我接的。 |
| We hit our target. | **We hit our target** three quarters in a row. | 我们连续三个季度达标。 |
| I trained two new people. | **I trained two new people** this year. | 今年我带了两名新人。 |
| I've been doing two jobs. | **I've been doing two jobs** since March. | 从三月起我一直在干两个人的活。 |

## 3. 说想学什么、想做什么

| 说法 | 例句 | 中文对照 |
|---|---|---|
| I'd like to learn + 技能. | **I'd like to learn** more about pricing. | 我想多学点定价方面的东西。 |
| I want to get better at + 技能. | **I want to get better at** presenting in English. | 我想把英文汇报练好。 |
| Is there training for this? | **Is there training for this** in the company? | 公司有这方面的培训吗？ |
| I'd be interested in + 方向. | **I'd be interested in** moving into product. | 我对转产品方向有兴趣。 |
| Can I shadow someone? | **Can I shadow someone** on the sales side? | 我能跟着销售那边学一阵吗？ |
| What would I need for that role? | **What would I need** for that role? | 那个岗位需要什么条件？ |

## 4. 提加薪

| 说法 | 例句 | 中文对照 |
|---|---|---|
| I'd like to talk about my salary. | **I'd like to talk about my salary.** | 我想谈谈我的薪资。 |
| I've taken on more responsibility. | **I've taken on more responsibility** this year. | 今年我承担的职责更多了。 |
| I'm below the market rate. | **I'm below the market rate** for this role. | 我这个岗位低于市场水平。 |
| Is there room for an increase? | **Is there room for an increase** this cycle? | 这轮有涨薪空间吗？ |
| What would I need to show? | **What would I need to show** for a raise? | 要加薪我需要做到什么？ |
| Can we revisit this in six months? | **Can we revisit this in six months?** | 我们半年后再谈一次行吗？ |

## 5. 收到反馈

| 说法 | 例句 | 中文对照 |
|---|---|---|
| That's fair. | **That's fair** — I'll work on it. | 说得对，我会改。 |
| Can you give me an example? | **Can you give me an example** of that? | 能举个例子吗？ |
| I didn't realize that. | **I didn't realize that** — thanks for telling me. | 我没意识到，谢谢你说出来。 |
| I see it differently. | **I see it differently** — can I explain? | 我看法不太一样，能让我说说吗？ |
| I'll put a plan together. | **I'll put a plan together** by next week. | 我下周前做个改进计划。 |
| That's good to hear. | **That's good to hear** — thanks. | 听你这么说我很高兴。 |

## 6. 常见错误

| 常见错误 | 正确说法 | 说明 |
|---|---|---|
| I want to raise my salary. | I'd like to discuss my salary. | 别直接说 want to raise。 |
| I am working here for 3 years. | I've worked here for three years. | 持续到现在用现在完成时。 |
| I did many contributions. | I contributed a lot. | contribution 是可数名词。 |
| I am very hard working. | I work hard. | 形容词拼作 hard-working。 |
| Please give me a promotion. | I'd like to be considered for a promotion. | 别用命令式要升职。 |
| My salary is too low. | I'd like to review my salary. | 别抱怨，改成商量的说法。 |
