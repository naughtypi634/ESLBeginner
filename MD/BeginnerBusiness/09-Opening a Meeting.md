# Opening a Meeting 会议开场

## 1. 等人到齐

| 说法 | 例句 | 中文对照 |
|---|---|---|
| Let's wait two minutes. | **Let's wait two minutes** for the Berlin team. | 我们等柏林那边两分钟。 |
| We'll start once Mei joins. | **We'll start once Mei joins** — she's dialing in. | 等 Mei 进来我们就开始，她在拨号。 |
| Can everyone see the agenda? | **Can everyone see the agenda** I sent? | 我发的议程大家能看到吗？ |
| While we wait — | **While we wait**, did everyone get the file? | 等的这会儿，文件大家都收到了吗？ |
| Let's give it one more minute. | **Let's give it one more minute**, then start. | 再等一分钟就开始。 |

## 2. 开场

| 说法 | 例句 | 中文对照 |
|---|---|---|
| Thanks for joining. | **Thanks for joining** — I know it's early for you. | 谢谢参加，我知道你们那边很早。 |
| Let's get started. | **Let's get started** — we have a lot today. | 我们开始吧，今天内容不少。 |
| Good morning, everyone. | **Good morning, everyone** — can you hear me OK? | 大家早上好，能听清吗？ |
| Let's jump in. | **Let's jump in** — first, the October numbers. | 我们直接开始，先看十月的数字。 |
| Thanks for making the time. | **Thanks for making the time** at short notice. | 谢谢大家临时挤出时间。 |
| I'll keep this to 30 minutes. | **I'll keep this to 30 minutes** — promise. | 我控制在 30 分钟内。 |

## 3. 说会议目的和议程

| 说法 | 例句 | 中文对照 |
|---|---|---|
| We're here to + 目的 | **We're here to** decide on the new supplier. | 我们今天是要定新供应商。 |
| Today we'll cover + 内容 | **Today we'll cover** three things. | 今天讲三件事。 |
| The purpose of this meeting is to… | **The purpose of this meeting is to** agree on the price. | 这次会议的目的是把价格定下来。 |
| On the agenda we have + 内容 | **On the agenda we have** the budget and the timeline. | 议程上有预算和时间表。 |
| I've called this meeting to… | **I've called this meeting to** talk about the delay. | 我召集这个会是想谈延期的事。 |
| We have 45 minutes. | **We have 45 minutes** — let's use them well. | 我们有 45 分钟，抓紧用。 |

## 4. 走议程

| 说法 | 例句 | 中文对照 |
|---|---|---|
| First… then… finally… | **First** the numbers, **then** the timeline, **finally** next steps. | 先看数字，再看时间表，最后说下一步。 |
| Let's start with + 第一项 | **Let's start with** the budget. | 我们先从预算开始。 |
| That's item two. | **That's item two** — we'll come back to it. | 那是第二项，我们回头再说。 |
| Moving on to + 下一项 | **Moving on to** the delivery schedule. | 接下来是交期。 |
| Let's leave that for now. | **Let's leave that for now** and take it offline. | 这个先放着，我们私下聊。 |

## 5. 确认大家都清楚

| 说法 | 例句 | 中文对照 |
|---|---|---|
| Does that make sense? | **Does that make sense** before I go on? | 我继续之前，这样讲清楚了吗？ |
| Are we all on the same page? | **Are we all on the same page** on the price? | 价格上大家理解一致吗？ |
| Any questions so far? | **Any questions so far?** | 到这儿有问题吗？ |
| Just so everyone knows… | **Just so everyone knows**, the client moved the date. | 跟大家说一下，客户改了日期。 |
| I'll put it in the chat. | **I'll put it in the chat** so you can follow. | 我发到对话框，你们能跟着看。 |

## 6. 常见错误

| 常见错误 | 正确说法 | 说明 |
|---|---|---|
| Let's begin our meeting. | Let's get started. | 口语里更常说 get started。 |
| Today's meeting content is three points. | We have three things today. | content 中式，用 things。 |
| I will host the meeting. | I'll run the meeting. | 主持会议用 run。 |
| Please attention. | Can I have your attention? | attention 是名词，要加动词。 |
| Everyone, listen to me. | Let's get started, everyone. | 别用命令式，直接宣布开始。 |
| We will discuss about the budget. | We'll discuss the budget. | discuss 后面不加 about。 |

## 7. Discussion 讨论

| Question | 中文对照 |
|---|---|
| Who usually runs meetings in your team? | 你们组一般谁主持会议？ |
| Do meetings at your work start on time? | 你们开会准时开始吗？ |
| Is there an agenda, or does it go everywhere? | 开会前有议程吗？还是想到哪说到哪？ |
| How long is a typical meeting for you? | 你们一般开多久？ |
| Do you speak up in the first five minutes? | 开会前五分钟你会发言吗？ |
