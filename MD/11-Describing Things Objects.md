# Describing Things & Objects · 描述物品

## 1. Warm-up 热身

| English | Chinese |
|---|---|
| You see a shared bike. What color is it? | 你看到一辆共享单车，它是什么颜色？ |
| → Blue / Yellow / Green | 蓝色 / 黄色 / 绿色 |
| What is your favorite daily thing? | 你最喜欢的日常物品是什么？ |
| → Phone / Wallet / Water cup | 手机 / 钱包 / 水杯 |

## 2. Useful Expressions 常用表达

### Colors 颜色 · Shapes 形状

| English | Chinese | Example |
|---|---|---|
| red / blue / green | 红 / 蓝 / 绿 | My phone case is **blue**. |
| black / white / yellow | 黑 / 白 / 黄 | The shared bike is **yellow**. |
| round / square | 圆的 / 方的 | The table is **round**. |
| big / small / long / short | 大 / 小 / 长 / 短 | It's a **small** bag. |

### Materials 材质 · Uses 用途

| English | Chinese | Example |
|---|---|---|
| metal / plastic | 金属 / 塑料 | The bottle is **plastic**. |
| glass / wood | 玻璃 / 木 | The cup is **glass**. |
| paper / cloth | 纸 / 布 | The bag is **cloth**. |
| for eating / for holding | 用来吃 / 用来拿 | A bowl is **for eating**. |
| for writing / for carrying | 用来写字 / 用来装 | A bag is **for carrying** things. |

## 3. Sentence Starters 句型开头

| English | Chinese | Keywords |
|---|---|---|
| My water bottle is **______**. | 我的水瓶是…… | blue / plastic / on the desk |
| The takeout box has a **______**. | 外卖盒有一个…… | lid / handle / square shape |
| The phone case is made of **______**. | 手机壳是……做的 | plastic / silicone / leather |

## 4. Discussion 讨论

| English | Chinese | Answer tags |
|---|---|---|
| Your phone case — what is it made of? | 你的手机壳是什么材质？ | Plastic / Silicone / Leather |
| A good phone case — what matters? | 好的手机壳，什么最重要？ | Look / Feel / Price |
| Your takeout box — metal or paper? | 你的外卖盒是金属还是纸的？ | Paper box / Plastic box / Metal box |
| Which container keeps food hot? | 哪种容器保温？ | Metal / Foam / Paper |
