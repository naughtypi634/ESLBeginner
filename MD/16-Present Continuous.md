# Present Continuous · 现在进行时

## 课程介绍

本周我们练习现在进行时，了解 am / is / are + doing 的五种常见用法，学会描述眼前动作、临时状态、变化、安排和反复发生的行为，并应用到工作、通勤和日常对话中。

## Form 形式

| English | Chinese |
|---|---|
| **Subject + am / is / are + verb-ing** | **主语 + am / is / are + 动词-ing** |
| I am working. / She is waiting. / They are talking. | 我正在工作。/ 她正在等待。/ 他们正在交谈。 |
| Negative: **Subject + am / is / are not + verb-ing** | 否定：主语 + am / is / are not + 动词-ing |
| Question: **Am / Is / Are + subject + verb-ing?** | 一般疑问：Am / Is / Are + 主语 + 动词-ing？ |
| Wh-question: **Wh-word + am / is / are + subject + verb-ing?** | 特殊疑问：疑问词 + am / is / are + 主语 + 动词-ing？ |

## Actions happening now 正在发生的动作

现在这一刻正在做的事，用现在进行时。看见动作、听见动作，或者用 **now / right now / at the moment** 指向此刻，都可以这样说。

| Type | English | Chinese |
|---|---|---|
| Affirmative 肯定 | I am scanning the QR code for my order. | 我正在扫订单二维码。 |
|  | Mei is waiting for the lift. | Mei 正在等电梯。 |
|  | We are discussing the rent in the group chat. | 我们正在群里讨论房租。 |
|  | The delivery rider is calling me now. | 外卖骑手现在正在给我打电话。 |
|  | My colleague is printing the report. | 我的同事正在打印报告。 |
| Negative 否定 | I am not checking my phone during the meeting. | 我没有在会议中看手机。 |
|  | He is not driving; he is taking the metro. | 他没有开车，他正在坐地铁。 |
|  | They are not ordering dessert. | 他们没有在点甜点。 |
|  | The baby is not sleeping yet. | 宝宝还没有睡觉。 |
|  | We are not discussing the problem now. | 我们现在没有讨论这个问题。 |
| Yes / No 一般疑问 | Are you working from home today? | 你今天在家办公吗？ |
|  | Is your manager joining the call? | 你的经理正在加入电话会议吗？ |
|  | Am I speaking too fast? | 我说得太快了吗？ |
|  | Are the students taking notes? | 学生们正在记笔记吗？ |
|  | Is your phone charging? | 你的手机正在充电吗？ |
| Wh-question 特殊疑问 | What are you cooking for dinner? | 你正在做什么晚饭？ |
|  | Where is Lin waiting? | Lin 正在哪里等？ |
|  | Why are they laughing? | 他们为什么在笑？ |
|  | Who is using the meeting room? | 谁正在使用会议室？ |
|  | What is the dog chasing? | 那只狗正在追什么？ |

## Temporary situations around now 这段时间的临时情况

不一定是说话这一秒正在做，但只发生在最近这段时间的临时情况，也用现在进行时。常和 **this week / these days / this month** 一起用。

| Type | English | Chinese |
|---|---|---|
| Affirmative 肯定 | I am staying with my cousin this week. | 这周我暂时住在表姐家。 |
|  | She is taking an online design course this month. | 她这个月正在上在线设计课。 |
|  | We are looking for a new flat these days. | 我们最近正在找新房子。 |
|  | My team is using a new work app this quarter. | 我们团队这季度正在用一个新的工作软件。 |
|  | I am reading more English news this month. | 我这个月正在读更多英文新闻。 |
| Negative 否定 | I am not commuting by car this week. | 这周我没有开车通勤。 |
|  | He is not living near the office anymore. | 他最近不住在公司附近了。 |
|  | We are not hiring this month. | 我们这个月不招人。 |
|  | They are not using the old meeting room today. | 他们今天不用旧会议室。 |
|  | She is not taking the bus this week. | 她这周没有坐公交车。 |
| Yes / No 一般疑问 | Are you learning to cook these days? | 你最近在学做饭吗？ |
|  | Is she working night shifts this month? | 她这个月在上夜班吗？ |
|  | Are they moving to a new office? | 他们最近要搬到新办公室吗？ |
|  | Is your company testing a shorter workweek? | 你们公司最近在试行更短的工作周吗？ |
|  | Are you using a new study app this month? | 你这个月在使用新的学习软件吗？ |
| Wh-question 特殊疑问 | What are you working on this week? | 你这周正在做什么项目？ |
|  | Where is your family staying this month? | 你家人这个月住在哪里？ |
|  | Why are you taking an evening class? | 你为什么最近在上晚课？ |
|  | Who is helping you with the move? | 谁最近在帮你搬家？ |
|  | What are you saving money for these days? | 你最近在为哪件事存钱？ |

## Changes and developing trends 正在变化和发展

想说“情况正在变成另一种样子”，用现在进行时。常见动词有 **getting, becoming, growing, changing, improving**。

| Type | English | Chinese |
|---|---|---|
| Affirmative 肯定 | The days are getting longer. | 白天正在变长。 |
|  | Food delivery prices are rising again. | 外卖价格又在上涨。 |
|  | My listening is improving. | 我的听力正在提高。 |
|  | More shops are accepting digital yuan. | 越来越多的商店正在接受数字人民币。 |
|  | The park is becoming busier at weekends. | 这个公园周末变得越来越热闹。 |
| Negative 否定 | The traffic is not getting better. | 交通状况没有变好。 |
|  | My workload is not becoming lighter. | 我的工作量没有变少。 |
|  | The old building is not changing quickly. | 这栋老楼变化不快。 |
|  | The service is not improving. | 服务没有改善。 |
|  | My pronunciation is not getting clearer yet. | 我的发音还没有变清楚。 |
| Yes / No 一般疑问 | Is the weather getting warmer? | 天气正在变暖吗？ |
|  | Are rents rising in this area? | 这个区域的房租在上涨吗？ |
|  | Is your English becoming easier? | 你的英语变得更容易了吗？ |
|  | Are more people using shared bikes? | 是不是越来越多人在用共享单车？ |
|  | Is the neighbourhood becoming quieter? | 这个社区变得更安静了吗？ |
| Wh-question 特殊疑问 | How is the project changing? | 这个项目正在怎样变化？ |
|  | Why are prices going up? | 价格为什么在上涨？ |
|  | What is getting easier for you? | 对你来说什么正在变容易？ |
|  | Which areas are growing fastest? | 哪些区域发展得最快？ |
|  | Why is the queue getting longer? | 队伍为什么越来越长？ |

## Fixed future arrangements 已经安排好的将来计划

已经约好、订好或排进日程的将来安排，也可以用现在进行时。通常有明确的时间，如 **tomorrow / tonight / next Friday**。

| Type | English | Chinese |
|---|---|---|
| Affirmative 肯定 | I am meeting my landlord tomorrow. | 我明天要见房东。 |
|  | We are having dinner with our clients tonight. | 我们今晚要和客户吃饭。 |
|  | She is flying to Chengdu next Friday. | 她下周五飞成都。 |
|  | They are moving into the new flat on Saturday. | 他们周六搬进新房子。 |
|  | I am having a job interview next Tuesday. | 我下周二要参加面试。 |
| Negative 否定 | I am not working this Sunday. | 我这周日不上班。 |
|  | He is not joining us for lunch tomorrow. | 他明天不和我们一起吃午饭。 |
|  | We are not taking the early train. | 我们不坐早班火车。 |
|  | She is not coming to the office next week. | 她下周不来办公室。 |
|  | I am not staying at the hotel tomorrow night. | 我明晚不住在这家酒店。 |
| Yes / No 一般疑问 | Are you seeing the doctor tomorrow? | 你明天要看医生吗？ |
|  | Is your team presenting on Friday? | 你们团队周五要做汇报吗？ |
|  | Are they visiting Beijing next month? | 他们下个月要来北京吗？ |
|  | Is he taking you to the station? | 他要送你去车站吗？ |
|  | Are you joining the workshop on Saturday? | 你周六参加这个工作坊吗？ |
| Wh-question 特殊疑问 | When are you leaving? | 你什么时候出发？ |
|  | Where are you staying tonight? | 你今晚住在哪里？ |
|  | Who are you meeting after work? | 你下班后要见谁？ |
|  | What are we doing this weekend? | 我们这周末要做什么？ |
|  | Why are you taking the train tomorrow? | 你明天为什么坐火车？ |

## Repeated habits that annoy us 令人烦恼的反复行为

和 **always / constantly / forever** 一起用时，现在进行时可以表达“老是这样”，通常带有说话人的不满或抱怨。它不是普通习惯，而是最近反复发生、让人注意到的行为。

| Type | English | Chinese |
|---|---|---|
| Affirmative 肯定 | You are always leaving your mug on my desk. | 你总是把杯子留在我桌上。 |
|  | He is constantly changing the meeting time. | 他总是在改会议时间。 |
|  | My neighbours are always drilling at lunchtime. | 我的邻居总是在午饭时间钻墙。 |
|  | She is forever checking the group chat. | 她老是在看群聊。 |
|  | You are always sending voice messages during work. | 你总是在工作时发语音。 |
| Negative 否定 | You are not always listening to the full message. | 你并不是总在听完整语音。 |
|  | He is not constantly missing deadlines. | 他并不是一直错过截止时间。 |
|  | They are not always arguing about money. | 他们并不是总在为钱争吵。 |
|  | I am not forever changing my plans. | 我并不是老在改计划。 |
|  | She is not always forgetting her keys. | 她并不是总忘带钥匙。 |
| Yes / No 一般疑问 | Are you always checking your phone at work? | 你是不是总在工作时看手机？ |
|  | Is he constantly interrupting people? | 他是不是总在打断别人？ |
|  | Are they always arriving late? | 他们是不是总是迟到？ |
|  | Am I always complaining? | 我是不是总在抱怨？ |
|  | Is your neighbour always playing loud music? | 你的邻居是不是总放大声音乐？ |
| Wh-question 特殊疑问 | Why are you always leaving the lights on? | 你为什么总是不关灯？ |
|  | Why is she constantly changing her mind? | 她为什么总是改变主意？ |
|  | Who is always sending messages at midnight? | 谁总是在半夜发消息？ |
|  | What are they always arguing about? | 他们总是在争论什么？ |
|  | Why are you always checking the delivery app? | 你为什么总是在看外卖软件？ |

## Conversation Questions 对话问题

| English | Chinese |
|---|---|
| What are you doing right now? | 你现在正在做什么？ |
| What is someone near you doing? | 你附近的某个人正在做什么？ |
| Are you working, studying, or relaxing tonight? | 你今晚是在工作、学习还是休息？ |
| Who are you talking to most this week? | 这周你和谁交流得最多？ |
| What are you learning these days? | 你最近正在学什么？ |
| What is changing in your work or study life? | 你的工作或学习生活有什么变化？ |
| Is your city getting busier? Why? | 你的城市变得更忙了吗？为什么？ |
| What are people doing on your street today? | 今天你那条街上的人们正在做什么？ |
| What are you doing after work tomorrow? | 你明天下班后要做什么？ |
| Who are you meeting this weekend? | 你这周末要见谁？ |
| What habit is someone around you always repeating? | 你身边有人总是在重复什么行为？ |
| What are you always reminding someone to do? | 你总是在提醒某人做什么？ |
