# Past Simple & Present Perfect · 过去时与现在完成时

## 课程介绍

本周我们练习一般过去时和现在完成时，了解两种时态的用法，学会用它们谈论经历和变化，并应用到分享故事和日常对话中。

## 1. Warm-up 热身

| English | Chinese |
|---|---|
| Have you ever used a 快递 locker? | 你用过快递柜吗？ |
| → Yes, I have / No, not yet / Only for packages | 用过 / 还没 / 只用来收件 |
| Is it easy to learn new apps? | 学新 App 容易吗？ |
| → Yes, very easy / Sometimes hard / I ask friends | 很容易 / 有时难 / 我问朋友 |

## 2. Useful Expressions 常用表达

### Experience Check 经历

| English | Chinese | Example |
|---|---|---|
| have tried / have used | 试过 / 用过 | I **have used** 美团 for years. |
| have been / have seen | 去过 / 见过 | I **have been** to that milk tea shop. |
| have ordered / have scanned | 点过 / 扫过 | She **has ordered** food online. |

### Finished Actions 已完成的动作（过去时）

| English | Chinese | Example |
|---|---|---|
| I ate / I went | 我吃了 / 我去了 | I **ate** noodles for lunch. |
| I paid / I sent | 我付了 / 我发了 | I **sent** the file yesterday. |
| I called / I picked | 我打了电话 / 我取了 | I **picked** up the package. |

### Changes Noticed 变化

| English | Chinese | Example |
|---|---|---|
| has changed / has moved | 变了 / 搬了 | The shop **has moved** to the corner. |
| has closed / has opened | 关了 / 开了 | A new café **has opened** downstairs. |
| has got / has become | 变得 | The weather **has got** cooler. |

### Recent Events 最近发生

| English | Chinese | Example |
|---|---|---|
| just arrived / just finished | 刚到 / 刚完成 | I **just finished** my report. |
| just paid / just left | 刚付 / 刚走 | He **just left** the office. |
| just saw / just got | 刚看到 / 刚拿到 | I **just got** the delivery. |

## 3. Sentence Starters 句型开头

| English | Chinese | Keywords |
|---|---|---|
| I **______** a shared bike this morning. | 今天早上我……共享单车。 | rode / have ridden / ride |
| She **______** a voice message on WeChat. | 她在微信上……语音。 | sent / has sent / sends |
| **______** you ever ordered food on 美团? | 你在美团上点过餐吗？ | Have / Did / Do |

## 4. Discussion 讨论

| English | Chinese | Answer tags |
|---|---|---|
| Have you ever ordered something strange on 美团? | 你在美团点过奇怪的东西吗？ | Yes, once / No, never / Only drinks |
| Did you finish a meal you did not like? | 你有没有硬着头皮吃完不喜欢的饭？ | Yes, I did / No, I stopped / I gave it away |
| Has 小程序 changed how you shop? | 小程序改变你的购物方式了吗？ | Yes, a lot / A little / Not really |
| Did you try a new app last week? | 上周你试新 App 了吗？ | Yes, I did / No, I did not / I forgot |
| Did you share a 小红书 post last weekend? | 上周末你发小红书了吗？ | Yes, I did / No, I did not / I only read |
