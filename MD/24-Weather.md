# Weather

## 课程介绍

本周我们练习天气词汇，掌握 20 个核心天气词及其含义，了解 rainy / sunny / windy / hot / cold 五类天气的常见表达与简单句型，练习描述眼前天气，并应用到穿衣、出行、心情与旅行话题的对话讨论中。

## Key Vocabulary

| Word | Meaning | Word | Meaning |
|---|---|---|---|
| sun | light from sky | rain | water from clouds |
| wind | moving air | cloud | shape in the sky |
| fog | cloud near ground | snow | soft white ice |
| storm | very bad weather | ice | frozen water |
| mist | light fog | frost | thin ice |
| breeze | light wind | drizzle | very light rain |
| shower | short rain | downpour | very heavy rain |
| thunder | loud storm sound | lightning | bright storm flash |
| hail | balls of ice | heat | high temperature |
| humidity | water in air | temperature | hot or cold level |

## Weather in detail

| Condition | Useful words and phrases | Example |
|---|---|---|
| rainy | drizzle / shower / downpour | Rainy today; take an umbrella. |
| sunny | bright / clear / mild | Sunny today; eat outside. |
| windy | breeze / strong wind | Windy on the bridge. |
| hot | warm / scorching / humid | Hot today; find shade. |
| cold | chilly / freezing / frost | Cold today; wear a jacket. |

## Useful patterns

| Pattern | Example |
|---|---|
| It is + adjective. | It is windy today. |
| There is + noun. | There is a shower. |
| The weather is + adjective. | The weather is mild. |
| I wear + noun when + adjective. | I wear a raincoat when rainy. |
| I prefer + weather + reason. | I prefer mild weather; it feels good. |

## Discussion

| Question | Useful words |
|---|---|
| What is today's weather? | sunny / cloudy / rainy / windy |
| What do you wear on rainy days? | raincoat / boots / jacket / umbrella |
| What do you do in a downpour? | stay inside / metro / taxi |
| What sunny activity do you enjoy? | walk / cycle / photos / picnic |
| Does weather affect your mood? | relaxed / tired / energetic |
| How does bad weather affect travel? | traffic / subway / taxi |
| Mild or hot weather? Why? | prefer / comfortable / because |
| Where would you go for snow or sun? | go to / visit / see |
| North or south China: different weather? | colder / drier / humid |
| How is your hometown's weather different? | similar / different / warmer |
| What should visitors bring in summer? | umbrella / sunscreen / water |
| When did weather change your plan? | planned / but / instead |
| Do you check the forecast before leaving? | app / clothes / transport |
