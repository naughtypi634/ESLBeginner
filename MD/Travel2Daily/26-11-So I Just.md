# So I Just ___, Right? · 确认一下

## 1. Dialogue 对话

| 说话人 | English | 中文 |
|---|---|---|
| 乘客 | So I just show this at the gate, right? | 我只要在登机口出示这个就行，对吗？ |
| 地勤 | Yes, and please keep your passport out. | 对，护照请拿在手上。 |
| 乘客 | Let me make sure I've got this right. Gate 18? | 我确认一下，是 18 号登机口吗？ |
| 地勤 | That's right. Boarding starts at 9:40. | 对。9 点 40 开始登机。 |
| 乘客 | So I don't need to check in again? | 那我不用再办一次值机了，对吧？ |
| 地勤 | Right. Just go straight to the gate. | 不用。直接去登机口就行。 |
| 乘客 | Got it. So I have about an hour, right? | 明白了。那我还有大概一小时，对吗？ |
| 地勤 | Yes. Have a good flight. | 对。祝您旅途愉快。 |

## 2. Pattern 句型公式

**So I just ___, right?**

| 用法 | 例句 | 中文对照 |
|---|---|---|
| 确认一步 | So I just show this at the gate, right? | 我只要在登机口出示这个就行，对吗？ |
| 确认不用做 | So I don't need to check in again? | 那我不用再办值机了，对吧？ |
| 确认时间 | So boarding starts at 9:40, right? | 9 点 40 开始登机，对吗？ |
| 换说法 | Let me make sure I've got this right. | 我确认一下我理解对了。 |
| 确认哪一个 | So I go to Gate 18, not 8? | 所以是 18 号登机口，不是 8 号？ |

| 槽位 | 例句 | 中文 |

| 不用办 | So I don't need a visa for this, right? | 这个不需要签证，对吗？ |

## 4. Answers 回答里会听到的

| Right. Just go straight to the gate. | 不用。直接去登机口就行。 |
