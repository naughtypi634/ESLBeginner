# I'd Like ... / I'm Looking For ... · 我想要

## 1. Dialogue 对话

| 说话人 | English | 中文 |
|---|---|---|
| 顾客 | Hi, I'd like a room for two nights. | 你好，我想订一个房间，住两晚。 |
| 前台 | Sure. A single or a double? | 好的。单人间还是双人间？ |
| 顾客 | A double, please. I'd like a quiet room. | 双人间。我想要安静一点的房间。 |
| 前台 | Let me check. I have one on the eighth floor. | 我查一下。八楼有一间。 |
| 顾客 | Great. I'm also looking for a good noodle place. | 太好了。我还想找家好吃的面馆。 |
| 前台 | There's one across the street. It's open late. | 马路对面有一家，开到很晚。 |
| 顾客 | Perfect. I'd like a late check-out too, if possible. | 太好了。可以的话我想晚点退房。 |
| 前台 | No problem. We can do 2 p.m. | 没问题，可以到下午两点。 |

## 2. Pattern 句型公式

**I'd like ___, please.**

| 用法 | 例句 | 中文对照 |
|---|---|---|
| 想要一个 | I'd like a double room, please. | 我想要一个双人间。 |
| 加上要求 | I'd like a quiet room, please. | 我想要安静一点的房间。 |
| 正在找 | I'm looking for a noodle place. | 我在找一家面馆。 |
| 要带条件的 | I'd like a room with a view. | 我想要有景观的房间。 |
| 直接定下来 | I'll take the double room. | 我要那间双人间。 |

## 6. Discussion 讨论

| Question | 中文对照 | Useful words |
|---|---|---|
| What do you usually order at a milk tea shop? | 你在奶茶店一般点什么？ | less ice / half sugar |
| Do you prefer a quiet room or a room with a view? | 你喜欢安静的房间还是有景观的？ | quiet / view |
| How do you ask for a smaller size? | 要小一号你会怎么说？ | smaller size |
| Have you ever changed an appointment? Why? | 你改过预约吗？为什么？ | reschedule |
| What are you looking for right now? | 你现在正在找什么东西？ | apartment / gym |

## 7. Practice 练习

### 填空

| # | 句子 | 答案 |
|---|---|---|
| 1 | I'd ______ a double room, please. | like |
| 2 | I'm ______ for a one-bedroom apartment. | looking |
| 3 | I'd like a room ______ a view. | with |
| 4 | I'd like it ______ no sugar, please. | with |
| 5 | Sorry, we only have smoking ______ left. | rooms |

### 造句

| 提示 | 例句 | 中文对照 |
|---|---|---|
| a large milk tea / less ice | I'd like a large milk tea with less ice. | 我要一杯大杯奶茶，少冰。 |
| a table for four / seven o'clock | I'd like a table for four at seven. | 我想订七点四个人的位子。 |
| a phone case / this model | I'm looking for a phone case for this model. | 我在找这款手机壳。 |
| change my appointment / Friday | I'd like to change my appointment to Friday. | 我想把预约改到周五。 |
| the vegetarian option | I'd like the vegetarian option, please. | 我要素食的那份。 |
