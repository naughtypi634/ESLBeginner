# Would You Like To…? 发出和回应邀请

## 1. 发出邀请

| 句型 | 例句 | 中文对照 |
|---|---|---|
| Would you like to + 动词原形? | **Would you like to** grab dinner after work? | 下班后想一起吃个饭吗？ |
| Do you want to + 动词原形? | **Do you want to** come over on Saturday? | 周六想来我这儿吗？ |
| How about + 动名词? | **How about** hotpot on Friday? | 周五吃火锅怎么样？ |
| Are you free + 时间? | **Are you free** Sunday afternoon? | 你周日下午有空吗？ |
| We should + 动词原形 + sometime | We **should** get coffee **sometime**. | 我们该找时间喝个咖啡。 |
| Let's + 动词原形 | **Let's** get barbecue — my treat. | 去吃烧烤吧，我请。 |

## 2. 接受邀请

| 例句 | 中文对照 |
|---|---|
| Yes, **I'd love to**. | 好啊，我很愿意。 |
| Sure, that **sounds fun**. | 好啊，听着挺有意思。 |
| **I'm in**. What time? | 算我一个，几点？ |
| **Count me in**. | 算我一个。 |
| Yeah, **let's do it**. | 行，就这么定了。 |
| That **works for me**. | 我这边可以。 |
| Sure — **I'll bring drinks**. | 行，我带上饮料。 |

## 3. 婉拒邀请

| 例句 | 中文对照 |
|---|---|
| Sorry, I **can't** — I'm on deadline this week. | 不好意思去不了，这周在赶截止日期。 |
| **I'd love to, but** I'm working late. | 我很想去，但要加班。 |
| Can I **take a rain check**? | 能改天吗？ |
| **I'm swamped** this weekend. Maybe next time? | 这周末忙爆了，下次吧？ |
| Thanks for asking, but **I'll pass** tonight. | 谢谢邀请，今晚我就不去了。 |
| I **have to get up early** tomorrow. | 我明天得起早。 |
| **Not tonight** — I'm wiped. | 今晚不行，我累瘫了。 |

## 4. 改约

| 例句 | 中文对照 |
|---|---|
| Can we **do it next week instead**? | 能改到下周吗？ |
| Something **came up** — can we push it to Thursday? | 临时有点事，能推到周四吗？ |
| Let's **aim for** Friday. I'll text you. | 就定周五吧，我再发你消息。 |
| I'll **let you know** by tomorrow morning. | 我明天早上给你答复。 |

## 5. 对话

| A | B |
|---|---|
| Are you free Friday night? | Yeah, what's up? |
| A few of us are getting barbecue. Want to come? | I'm in. What time? |
| Around 7, at the place by the subway exit. | Perfect. See you there. |

| A | B |
|---|---|
| Would you like to see a movie on Saturday? | I'd love to, but I'm working Saturday. |
| No worries — how about Sunday? | Sunday works. Let's do it. |

| A | B |
|---|---|
| Hey, we're doing hotpot tonight. You in? | Ah, I can't — I'm wiped. Can I take a rain check? |
| Of course. Next week, my treat. | Deal. |

## 6. Discussion 讨论

| Question | 中文对照 |
|---|---|
| How often do you invite friends out? | 你多久约一次朋友？ |
| What do you usually do with your friends? | 你一般和朋友干什么？ |
| Do you make plans ahead or go with the flow? | 你是提前计划还是随性？ |
| What would you like to do for your birthday? | 你生日想怎么过？ |
| How do you feel when someone says no? | 别人拒绝你时你会怎么想？ |
| What's the last invitation you turned down? Why? | 你最近一次拒绝邀请是什么？为什么？ |
| Would you rather go out or host at home? | 你更喜欢出去还是在家聚？ |
| Who's the hardest person to make plans with? | 谁最难约？ |
| Have you ever regretted saying yes? | 你有没有答应了之后后悔过？ |
| What would you like to try that you never have? | 你有什么一直想试但没试过的？ |

### 造句

| 提示 | 例句 | 中文对照 |
|---|---|---|
| would you like to / grab dinner | Would you like to grab dinner after work? | 下班后想一起吃个饭吗？ |
| I'd love to, but / working late | I'd love to, but I'm working late. | 我很想去，但要加班。 |
| how about / Sunday / instead | How about Sunday instead? | 改到周日怎么样？ |
| can I / take a rain check | Can I take a rain check? I'm wiped tonight. | 能改天吗？我今晚累瘫了。 |
