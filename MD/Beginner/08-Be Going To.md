# Be Going To 谈打算和计划

## 1. be going to 形式

| 结构 | 例句 | 中文对照 |
|---|---|---|
| 肯定：am / is / are + going to + 动词原形 | **I'm going to** sleep for 12 hours. | 我要睡12个小时。 |
| 第三人称单数用 is | **She's going to** start a part-time master's program in September. | 她九月要开始读在职硕士。 |
| 否定：am not / isn't / aren't going to | **I'm not going to** buy anything on Double 11. | 双十一我什么都不打算买。 |
| 疑问：Are / Is + 主语 + going to | **Are** you **going to** stay at that job? | 你打算继续干那份工作吗？ |
| 简答 | Yes, I **am**. / No, I'm **not**. | 打算。/ 不打算。 |
| 特殊疑问：What are you going to…? | **What are you going to** do on National Day? | 国庆你打算干嘛？ |

### 常见错误

| 常见错误 | 正确说法 | 说明 |
|---|---|---|
| I going to travel. | **I'm going to** travel. | going to 前面必须有 be 动词 |
| I'm going to traveling. | I'm going to **travel**. | going to 后面用动词原形 |
| I'm go to travel. | **I'm going to** travel. | 是 going to，不是 go to |
| I will going to travel. | **I'm going to** travel. | going to 不和 will 连用 |

## 2. 谈打算和计划

| 句型 | 例句 | 中文对照 |
|---|---|---|
| be going to + 动词 | **We're going to** book tickets the second they go on sale for National Day. | 国庆的票一开抢我们就订。 |
| be going to + 动词 | **I'm going to** finally use my gym membership before it expires. | 我要在健身卡过期前用掉它。 |
| be going to + 动词 | My parents **are going to** visit in October, so I'll clean up. | 我爸妈十月要来，我得好好打扫。 |
| be going to + 动词 | **I'm going to** ask for a raise at my review next month. | 下个月考核我打算提加薪。 |
| be not going to + 动词 | **I'm not going to** stay up past midnight. | 我不打算再熬夜了。 |

### be going to 还是现在进行时

| 想表达 | 用哪个 | 例句 |
|---|---|---|
| 打算、有意图，但没定死 | be going to | **I'm going to** look for a new apartment next month. |
| 已经安排好、定死了 | 现在进行时 | **I'm viewing** an apartment at 3 p.m. tomorrow. |
| 只凭感觉预测 | be going to | Look at those clouds — **it's going to** rain. |

## 6. Practice 练习

| 序号 | 句子 |
|---|---|
| 1 | I ______ (sleep) for 12 hours this weekend — I've earned it. |
| 2 | ______ you ______ (buy) anything on Double 11? |
| 3 | She ______ (start) a part-time master's program in September. |
| 4 | We ______ (not / book) the tickets yet — we're waiting for a sale. |
| 5 | My parents ______ (visit) in October, so I need to clean. |

| 序号 | 句子 |

### 造句

| 提示 | 例句 | 中文对照 |
|---|---|---|
| I / going to / sleep in / Saturday | I'm going to sleep in on Saturday — no alarm. | 周六我要睡到自然醒，不定闹钟。 |
| we / going to / book tickets / National Day | We're going to book tickets the day they drop. | 票一开抢我们就订。 |
| I / not going to / buy / anything / Double 11 | I'm not going to buy anything on Double 11. | 双十一我什么都不打算买。 |
| what / you / going to / do / long weekend | What are you going to do for the long weekend? | 小长假你打算干嘛？ |
