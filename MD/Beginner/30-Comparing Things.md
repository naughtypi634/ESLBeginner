# Comparing Things 比较与最高级

## 1. 比较级形式

| 规则 | 变化 | 例句 |
|---|---|---|
| 短词加 -er | cheap → cheaper | The left app is **cheaper** for the same order. |
| 以 e 结尾加 -r | nice → nicer | This bubble tea shop is **nicer** than the old one. |
| 辅音 + y 变 i 加 -er | busy → busier | The subway is **busier** after 6 p.m. on Fridays. |
| 重读闭音节双写末尾字母 | big → bigger | My new place is **bigger** and closer to the subway. |
| 长词用 more | expensive → more expensive | Rent near the subway is **more expensive** now. |
| 不规则（好／坏） | good → better ／ bad → worse | The train is **better** than flying for this trip. |
| 不规则（远） | far → farther | My new office is **farther** from the subway. |
| 不规则（多） | many ／ much → more | I spend **more** time on the subway than before. |
| 不规则（少） | little → less | This route has **less** traffic in the morning. |

## 2. 最高级形式

| 规则 | 变化 | 例句 |
|---|---|---|
| 最高级前加 the | the cheapest ／ the best | This shop has **the cheapest** milk tea nearby. |
| 短词加 -est | small → the smallest | That's **the smallest** apartment I've seen here. |
| 以 e 结尾加 -st | nice → the nicest | That noodle shop is **the nicest** on our street. |
| 辅音 + y 变 i 加 -est | busy → the busiest | Friday night is **the busiest** time for deliveries. |
| 重读闭音节双写末尾字母 | big → the biggest | This is **the biggest** mall on the subway line. |
| 长词用 the most | expensive → the most expensive | Rent there is **the most expensive** nearby. |
| 不规则（好） | good → the best | This is **the best** takeout deal in the building. |
| 不规则（坏） | bad → the worst | That was **the worst** commute this month. |
| 不规则（远） | far → the farthest | This stop is **the farthest** from my office. |
| 不规则（多） | many ／ much → the most | This app has **the most** deals on Double Eleven. |
| 不规则（少） | little → the least | Tuesday is **the least** busy day at my store. |

## 3. 比较的句型

| 句型 | 例句 | 中文对照 |
|---|---|---|
| A is **cheaper than** B | The left app is **cheaper than** the right one. | 左边的外卖比右边便宜。 |
| This one is **the best** deal. | This one is **the best** deal for a two-year lease. | 这套租两年最划算。 |
| It's **as good as** … | The new one is **as good as** the one I had. | 新的跟原来的一样好。 |
| It's **not as spicy as** … | This hotpot is **not as spicy as** I expected. | 这家火锅没我想的辣。 |
| **Which one** do you like better? | **Which one** is better — the milk tea or the coffee? | 奶茶和咖啡哪个更好？ |
| It's **the same as** … | This milk tea is **the same as** the one downstairs. | 这杯奶茶和楼下那家一样。 |
| It's **different from** … | This gym is **different from** the one I joined. | 这家健身房跟我办卡那家不一样。 |
| A is **more useful than** B | This app is **more useful than** the old one. | 这个应用比旧的更有用。 |
| It's **worth more than** … | The free trial is **worth more than** a coupon. | 免费试用比优惠券更值。 |

## 4. 哪个更划算／更方便／更值得

| 句型 | 例句 | 中文对照 |
|---|---|---|
| Which is a **better deal**? | Which is a **better deal** — yearly or monthly? | 年卡和月卡哪个更划算？ |
| Which is **more convenient**? | Which is **more convenient** — subway or bike? | 地铁和骑车哪个更方便？ |
| It's **worth it**. | The express train is **worth it** for the time. | 高铁省时间，多花点值。 |
| It's **not worth it**. | Waiting a week is **not worth it** for ten yuan. | 为十块钱等一周不值。 |

## 5. 一样与不同

| 句型 | 例句 | 中文对照 |
|---|---|---|
| A is **the same as** B | The mall price is **the same as** the app. | 商场和App价格一样。 |
| A is **different from** B | My night shift is **different from** my old job. | 我的夜班和以前不一样。 |
| A is **similar to** B | Her music taste is **similar to** mine. | 她的音乐品味和我差不多。 |
| A is **not the same as** B | The tea here is **not the same as** before. | 这里的奶茶和以前不一样。 |

## 6. 成对的比较词

| English | 中文 | English | 中文 |
|---|---|---|---|
| better | 更好 | worse | 更差 |
| cheaper | 更便宜 | more expensive | 更贵 |
| faster | 更快 | slower | 更慢 |
| busier | 更忙 | quieter | 更安静 |
| easier | 更容易 | harder | 更难 |
| closer | 更近 | farther | 更远 |
| bigger | 更大 | smaller | 更小 |
| newer | 更新 | older | 更旧 |
| hotter | 更热 | colder | 更冷 |
| safer | 更安全 | riskier | 更危险 |

## 7. 常见错误

| 常见错误 | 正确说法 | 说明 |
|---|---|---|
| This is more cheaper. | This is **cheaper**. | 不能同时用 more 和 -er。 |
| He is more tall than me. | He is **taller** than me. | 短词用 -er，不用 more。 |
| It's the most cheap. | It's the **cheapest**. | 短词最高级用 -est。 |
| My apartment is more small. | My apartment is **smaller**. | 短词比较级不用 more。 |
| Shanghai is bigger than any city in China. | Shanghai is bigger than **any other** city in China. | 比较范围要排除自己。 |
| It's not as cheaper as mine. | It's not as **cheap** as mine. | as…as 中间用原级。 |
